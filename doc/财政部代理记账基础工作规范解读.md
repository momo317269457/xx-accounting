## 二、制定背景与意义

### 1. 贯彻落实中央决策部署
- 习近平总书记多次就严肃财经纪律、将财会监督纳入党和国家监督体系作出重要指示
- 2023年2月，中办、国办印发《关于进一步加强财会监督工作的意见》，要求加强对代理记账机构执业质量的把控

### 2. 健全行业监管机制
- 全国现有取得行政许可的代理记账机构**超过10万家**，从业人员**超过30万人**
- 行业迅速发展，执业质量参差不齐
- 《工作规范》与《会计法》、《代理记账管理办法》共同形成行业管理制度规范体系

### 3. 提升执业质量
- 解决执业标准不统一、覆盖范围有限、权威性不够高等问题
- 出台行业统一的执业标准，推动代理记账机构全面遵照执行

## 三、正文九章核心内容

《工作规范》正文共**九章四十五条**，以代理记账业务的主要工作流程为主线：

### 第一章 总则（第1-4条）

| 条款 | 内容要点 |
|------|---------|
| 制定依据 | 《会计法》、《代理记账管理办法》等 |
| 适用范围 | 代理记账机构开展代理记账业务 |
| 基本程序 | 业务承接→工作计划→资料交接→会计核算→质量控制→档案管理 |

### 第二章 业务承接（第5-9条）

核心要求：
- **了解委托人基本情况**：经营规模、行业特点、财务状况等
- **评估自身承接能力**：是否有相应专业胜任能力
- **签订委托合同**：明确服务内容、双方权利义务、收费标准
- **不得承接情形**：超出自身能力、委托人提供虚假信息等

### 第三章 工作计划（第10-16条）

核心要求：
- 为每个委托项目**编制工作计划**
- 计划内容包括：工作内容、时间安排、人员分工、注意事项
- 计划需经**审核**后方可执行
- 遇重大变化需**及时调整**计划

### 第四章 资料交接（第17-21条）

| 场景 | 要求 |
|------|------|
| **初次接受委托** | 与委托人办理完整资料交接，填写交接清单 |
| **日常交接** | 每月/每季度按约定时间交接票据、凭证 |
| **终止委托关系** | 办理会计档案移交，双方签字确认 |
| **交接内容** | 原始凭证、记账凭证、账簿、报表、其他会计资料 |

**重点关注**：《资料交接手册（参考范例）》和《原始凭证交接表（参考范例）》是附录中的重要实操工具。

### 第五章 会计核算（第22-24条）

核心要求：
- 按照国家统一会计制度进行会计核算
- 不得伪造、变造会计凭证
- 确保会计信息真实、完整

### 第六章 质量控制（第25-33条）★ 核心章节（9条）

| 要求 | 具体内容 |
|------|---------|
| **岗位设置** | 明确各岗位职责，不相容岗位分离 |
| **工作委派** | 根据人员专长和胜任能力合理委派工作 |
| **复核制度** | 建立**三级复核**制度（制单→复核→主管审核） |
| **复核内容** | 凭证审核、账务核对、报表审核、税款计算 |
| **信息沟通** | 建立内部信息沟通机制，及时传达客户问题和政策变化 |
| **投诉管理** | 建立客户投诉处理机制，留存记录 |

**三级复核制度详解：**

```
第一级：制单会计 → 自查凭证的准确性、完整性
第二级：复核会计 → 复核账务处理的合规性、一致性
第三级：主管审核 → 审核财务报表和纳税申报的准确性
```

### 第七章 人员管理（第34-37条）

| 要求 | 说明 |
|------|------|
| **资格条件** | 从业人员需具备会计专业基础知识和业务能力 |
| **专业胜任能力** | 持续学习，保持专业水平 |
| **职业道德** | 诚实守信、客观公正、保守秘密 |
| **继续教育** | 每年参加继续教育，更新知识 |
| **机构责任** | 机构应对从业人员进行岗前培训和定期业务培训 |

### 第八章 档案管理（第38-41条）

| 要求 | 说明 |
|------|------|
| 档案范围 | 委托合同、工作计划、资料交接单、凭证、账簿、报表 |
| 保管期限 | **不少于10年**（原始凭证、记账凭证） |
| 保管要求 | 专人负责、专柜存放、防潮防火防盗 |
| 电子档案 | 电子会计档案需符合《电子会计档案管理暂行办法》 |

### 第九章 附则（第42-45条）

- 法律责任：违反规定依照《会计法》、《代理记账管理办法》处理
- 施行日期：**2024年1月1日起施行**

## 四、附录五项参考范例

财政部同步发布了5个参考范例，对代理记账机构规范执业具有直接指导意义：

### 1. 《代理记账业务委托合同（参考范例）》
- 包括服务内容、费用标准、双方权利义务
- 保密条款、违约责任、争议解决
- 签订合同时建议参照此范本

### 2. 《代理记账业务工作计划（参考范例）》
- 客户名称、委托期限、服务内容
- 每月工作安排、人员分工
- 审核人和批准人签名

### 3. 《资料交接手册（参考范例）》
- 初次交接和日常交接的流程
- 交接时间、地点、参与人员
- 交接清单模板

### 4. 《原始凭证交接表（参考范例）》
- 凭证类型（发票、银行回单、工资表等）
- 数量、日期、交接人签名
- 一式两份，双方各执一份

### 5. 《会计档案移交清册（参考范例）》
- 终止委托关系时使用
- 列明移交的全部会计资料
- 双方签字盖章确认

## 五、实施指导与注意事项

### 1. 兼容性考虑
- 《工作规范》体现代理记账业务的基本要求
- 既要让大多数机构能够得着，也要推动行业向专业化发展

### 2. 政策衔接
- 会计核算、档案管理、信息化建设等已有具体规定的，从其规定
- 《工作规范》仅做原则性规定

### 3. 行业协会的角色
- 代理记账行业协会可根据《工作规范》制定协会会员执业指引
- 需报所在地财政部门审核后施行

### 4. 地方财政部门
- 各省级财政部门可根据《工作规范》细化本区域内统一的执业指引

## 六、对代账公司的实操影响

| 影响方面 | 具体要求 | 落实建议 |
|---------|---------|---------|
| **业务承接** | 必须签订正式委托合同 | 使用财政部参考范本修改 |
| **工作计划** | 每个客户要有工作计划 | 建立客户档案管理制度 |
| **资料交接** | 严格交接签收制度 | 使用标准化交接表格 |
| **质量控制** | 三级复核制度 | 建立内部审核流程 |
| **人员管理** | 配备专职会计人员 | 不得用兼职会计替代 |
| **档案管理** | 至少保存10年 | 建立电子+纸质双备份 |
