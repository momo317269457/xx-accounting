# 代理记账公司组织架构及岗位职责

> 来源：百度文库、原创力文档、好顺佳等

## 一、组织架构

### 核心部门设置

```
                    ┌─────────────┐
                    │   总经理     │
                    └──────┬──────┘
                           │
        ┌──────────────────┼──────────────────┐
        │                  │                  │
   ┌────┴─────┐      ┌────┴─────┐      ┌────┴─────┐
   │  业务部    │      │  会计部    │      │  行政部    │
   └────┬─────┘      └────┬─────┘      └────┬─────┘
        │                  │                  │
   ┌────┴─────┐      ┌────┴────────┐   ┌────┴─────┐
   │ 销售组    │      │ 记账会计组   │   │ 人事行政   │
   │ 客服组    │      │ 审核会计组   │   │ 档案管理   │
   └──────────┘      │ 税务申报组   │   └──────────┘
                     └─────────────┘
```

### 部门职责

1. **行政部门**：人力资源管理、办公设施管理、物资采购、日常事务管理
2. **销售部门**：营销和客户服务、拓展新客户、维护现有客户关系、制定销售策略
3. **财务部门（核心）**：记账、开具发票、核对账目、编制财务报表、处理税务事务

## 二、岗位设置及职责

### 1. 代理记账业务负责人（主管会计）

- 审核记账凭证，确保原始单据符合相关规定及记账科目符合会计规定
- 最终审核财务报表，确保财务报表正确合理
- 监督指导会计团队工作

### 2. 记账会计

- 接收并整理客户票据
- 编制记账凭证
- 登记会计账簿
- 编制财务报表

### 3. 审核会计

- 复核记账会计的工作成果
- 检查科目使用是否正确
- 核实税务计算的准确性

### 4. 税务申报专员

- 负责各税种的纳税申报
- 跟踪税收优惠政策
- 处理税务异常

### 5. 客户经理/财税顾问

- 客户沟通与维护
- 解答客户财税疑问
- 提供财税咨询建议

### 6. 外勤会计

- 办理工商、税务现场业务
- 银行开户、变更等外勤工作
- 资料递送

## 三、岗位人员配置建议

| 公司规模 | 记账会计 | 审核会计 | 外勤 | 客服 |
|---------|---------|---------|------|------|
| 初创期（<50家客户） | 1-2人 | 1人（兼） | 1人 | 1人（兼） |
| 成长期（50-200家客户） | 3-5人 | 1-2人 | 1-2人 | 1-2人 |
| 成熟期（>200家客户） | 5-10人 | 2-3人 | 2-3人 | 2-3人 |

> 注：每位全职记账会计通常可服务50-80家小规模纳税人客户，或30-50家一般纳税人客户。
