# 代账公司出口退税业务全流程指南

> 综合来源：中申国贸、知乎专栏、大数跨境、国家税务总局等
> 整理时间：2026年6月

---

## 一、出口退税基础认知

### 什么是出口退税？

出口退税是指国家将出口货物已缴纳的增值税和消费税退还给出口企业，使出口商品以不含税价格进入国际市场。

### 退税率档次（2026年）

| 退税率 | 适用商品类型 |
|-------|-------------|
| 16% | 集成电路、生物医药、新能源装备等高端制造产品 |
| 13% | 机电设备、高科技产品 |
| 9% | 农产品加工、部分化工产品 |
| 6% | 部分服务贸易 |
| 0% | "两高一资"类产品（高污染、高能耗、资源型） |

### 生产企业 vs 外贸企业退税差异

| 项目 | 生产企业 | 外贸企业 |
|------|---------|---------|
| **退税方式** | 免抵退税 | 免退税 |
| **核心逻辑** | 免销项税、抵内销应纳、退未抵完部分 | 免销项税、退进项税 |
| **退税额计算** | 出口离岸价×退税率 - 抵减额 | 增值税专票不含税金额×退税率 |
| **适用对象** | 有生产能力的企业 | 纯贸易型企业 |

## 二、2026年出口退税核心政策变化

### 1. 智慧退税全面实施
- 税务总局与海关总署联合推进"智慧退税"工程
- 申报数据四方自动比对（报关单、收汇水单、采购发票、物流信息）
- 差异超过5%触发人工核查

### 2. 退税率季度动态调整
- 从年度集中修订转为**季度动态优化**
- 高端制造产品退税率阶梯式上调至16%
- 传统劳动密集型商品维持原有水平

### 3. 分类管理标准细化

| 等级 | 条件 | 退税待遇 |
|------|------|---------|
| A+级 | 报关准确率99.8%+，收汇及时率100% | 先退后审，48小时到账 |
| A级 | 无重大差错 | 正常审核，约9天到账 |
| B级 | 有少量差错记录 | 加强审核，约23天到账 |
| C级 | 差错率高或有违规记录 | 100%单证核查+实地稽查 |

### 4. 关键时限硬化
- 出口之日次月起至**次年4月30日前**完成申报
- 2026年新规：**36个月内**必须完成申报+收汇
- 逾期未完成直接**视同内销缴税**

## 三、出口退税必备条件与资质

### 企业需满足的条件

1. **一般纳税人资格**（小规模纳税人只能免税，不能退税）
2. **进出口收发货人登记**（海关备案）
3. **出口退（免）税备案**（电子税务局操作）
4. **电子口岸开通**（获取IC卡/UKey）
5. **外汇名录登记**（外管局备案）
6. **货物实际离境**并完成报关
7. **已收汇**（2026年起单证/收汇是前置条件）

### 资质办理"三步走"

```
第一步：办理进出口经营权备案（商务局）
    ↓
第二步：申请电子口岸卡（海关）
    ↓
第三步：出口退（免）税备案（电子税务局，即时办结）
```

## 四、出口退税全流程实操

### 完整流程图

```
出口报关 → 收汇核销 → 收集单证（三单一致） 
→ 增值税申报 → 免退税正式申报 → 税务审核 → 退税到账 → 单证备案
```

### 第一阶段：出口与单证收集

**核心要求：三单一致**
- **报关单**、**增值税专票**、**出口发票**的品名、单位、数量、金额必须完全匹配
- 发票备注栏需注明：报关单号、外币币种、汇率、成交方式

**需收集的单证：**
| 单证名称 | 来源 | 保存要求 |
|---------|------|---------|
| 出口报关单（退税联） | 电子口岸/单一窗口 | 电子+纸质双备份 |
| 增值税专用发票（退税勾选） | 供应商 | 已做退税勾选（非抵扣勾选） |
| 出口发票（0税率/免税） | 企业自开 | 与报关单信息一致 |
| 收汇水单/结汇凭证 | 银行 | 证明已收汇 |
| 外贸合同 | 客户 | 保存原件或扫描件 |
| 提单/运单 | 货代/物流 | 证明货物已发运 |
| 装箱单 | 企业自开 | 与报关单一致 |

⚠️ **关键提醒**：增值税专票必须做**退税勾选**，绝对不能选**抵扣勾选**。一旦选错直接无法退税！

### 第二阶段：增值税申报（次月）

**操作步骤：**
1. 货物出口次月申报期内
2. 登录电子税务局完成增值税申报
3. 主表中填报**免税销售额**
4. 附表一选择"免税-出口货物"栏次
5. 退税对应的进项税**不抵扣、不转出**，留待免退税申报

### 第三阶段：免退税正式申报（核心步骤）

**第1步：数据采集**
- 登录电子税务局→我要办税→出口退税管理→免退税申报
- 导入出口报关单电子数据
- 录入出口发票和增值税专票信息
- 准确填写出口汇率、商品海关编码

**第2步：数据自检**
- 系统自动校验三单一致、退税率匹配、发票已做退税勾选
- 出现疑点立即修正
- 生成：进货明细表、出口明细表、汇总表

**第3步：正式申报**
- 上传所有电子数据和报表
- 提交申报，等待税务机关审核

### 第四阶段：审核与退库

| 审核阶段 | 内容 | 时间 |
|---------|------|------|
| 系统自动审核 | 数据比对、异常检测 | 即时 |
| 人工审核 | A+级免审，其他等级抽查 | 1-15天 |
| 退库 | 税款退至企业对公账户 | 审核通过后1-3天 |

### 第五阶段：单证备案（申报后15日内）

**备案保存期：5年**

备案资料包括：
- 报关单
- 出口发票
- 增值税专用发票
- 收汇水单
- 外贸合同
- 物流单（提单/运单）
- 装箱单

建议：电子档和纸质档双备份，按申报批次建立专门档案。

## 五、出口退税计算

### 外贸企业退税额计算

```
应退税额 = 增值税专票不含税金额 × 对应商品退税率
```

**示例**：某外贸企业出口一批机电产品
- 增值税专票不含税金额：1,000,000元
- 机电产品退税率：13%
- 应退税额：1,000,000 × 13% = **130,000元**

**注意**：如果商品退税率 < 征税率，差值部分直接计入采购成本。

### 生产企业退税额计算（免抵退税）

```
当期应纳税额 = 内销销项税 -（进项税 - 免抵退不得免征和抵扣税额）
免抵退税额 = 出口离岸价 × 退税率
应退税额 = min（当期留抵税额，免抵退税额）
```

## 六、代账公司如何开展出口退税服务

### 服务模式选择

| 模式 | 说明 | 适合代账公司 |
|------|------|------------|
| **协助申报** | 帮助企业整理单证、录入数据 | 有基础外贸知识 |
| **全权代理** | 从备案到申报到账全流程代办 | 有专业退税团队 |
| **双代理模式** | 出口报关代理+退税申报代理一体化 | 与货代合作 |
| **培训+辅导** | 教企业自己做，审核把关 | 轻资产模式 |

### 服务收费参考

| 服务类型 | 收费标准 | 利润空间 |
|---------|---------|---------|
| 单次退税申报 | 500-2,000元/次 | 中等 |
| 年度退税代理 | 3,000-10,000元/年 | 中等 |
| 双代理（报关+退税） | 按报关单+退税提成 | 较高 |
| 退税培训+系统搭建 | 10,000-50,000元/次 | 高 |

### 2026年新规下的操作要点

1. **申报顺序不能反**：先做退税勾选→再完成增值税申报→最后做免退税正式申报
2. **单证/收汇是硬条件**：不再允许先申报后补资料
3. **全电发票要求更高**：必须做到**四流一致**（票流、货流、资金流、合同流）
4. **四流不符**直接影响退税

### 常见风险规避

| 风险点 | 规避方法 |
|-------|---------|
| 商品编码错误 | 使用最新版退税率文库，首次申报前核对 |
| 汇率核算错误 | 以央行公布中间价为准，一经确定一年不变 |
| 收汇逾期 | 建立收汇跟踪机制，到期前催收 |
| 单证不一致 | 严格三单一致，报关单与发票逐项核对 |
| 供应商发票风险 | 核查供应商是否正常经营、发票是否真实 |
