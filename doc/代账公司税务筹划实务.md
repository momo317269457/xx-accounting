## 一、税务筹划的合法边界

合法税务筹划 ≠ 偷税漏税，核心原则：

> **"该交的税一分不少，不该交的税一分不多"**

### 合法筹划 vs 违法避税的界限

| 合法税务筹划 | 违法避税/偷税 |
|------------|-------------|
| 在税法框架内安排经营活动 | 虚构交易、隐匿收入 |
| 利用优惠政策降低税负 | 虚开发票、伪造凭证 |
| 事前规划，合理商业目的 | 事后补救，滥用税收洼地 |
| 具有真实业务背景 | 空壳公司、无实质经营 |

### 2026年税务监管态势
- 金税四期全面运行，**大数据监控**能力大幅提升
- 税务总局明确"三性原则"：动机合理性、业务真实性、交易公允性
- 利用税收洼地、政策适用主体错配等行为纳入重点稽查范围

## 二、企业全生命周期税务筹划

### 初创期筹划

| 筹划点 | 策略 | 节税效果 |
|-------|------|---------|
| **企业身份选择** | 小型微利企业（年应纳税所得额≤300万，实际税率5%） | 税负降低75% |
| **组织形式选择** | 个体工商户/个人独资企业 vs 有限责任公司 | 个独综合税负低于公司 |
| **注册地点选择** | 西部大开发地区、自贸区、特定产业园（15%企业所得税） | 税率降低40% |
| **研发费用归集** | 按高新技术企业标准搭建 | 认定后税率降至15% |

#### 案例：小型微利企业优惠

**筹划前**：设计工作室年利润80万，有限责任公司查账征收
- 企业所得税：80万×25%=20万
- 分红个税：(80-20)×20%=12万
- **总税负：32万**

**筹划后**：符合小型微利企业条件
- 企业所得税：80万×5%=4万（省16万）
- 通过合理工资方式提取利润
- **总税负大幅降低**

### 成长期筹划

| 筹划点 | 策略 |
|-------|------|
| **研发费用加计扣除** | 2026年制造业加计扣除比例提高至120% |
| **固定资产一次性扣除** | 500万元以下设备一次性税前扣除 |
| **业务分拆** | 将研发/销售部门独立为小微企业 |
| **供应链布局** | 在税收优惠地区设立采购/销售子公司 |

### 成熟期筹划

| 筹划点 | 策略 |
|-------|------|
| **利润分配** | 工资与分红的黄金比例（平衡公司税和个人税） |
| **股权架构** | 利用有限公司→合伙企业嵌套降低分红税负 |
| **资产配置** | 公益捐赠（利润总额12%以内限额扣除） |
| **集团内转让定价** | 合规制定关联交易价格（独立交易原则） |

### 清算期筹划

| 筹划点 | 策略 |
|-------|------|
| **资产处置时机** | 选在亏损年度处置亏损资产，用亏损抵扣收益 |
| **清算所得控制** | 合理安排清算期间的费用支出 |
| **税务注销** | 确保完成所有清算申报后再注销 |

## 三、代账公司可提供的12种税务筹划方案

> 以下方案均适用于代账公司向客户提供的增值服务

### 方案1：纳税人身份选择
- 小规模纳税人（3%征收率）vs 一般纳税人（6%/9%/13%）
- 根据客户采购方需求、进项比例、年销售额综合判断
- 2026年小规模纳税人月销售额10万以下免征增值税

### 方案2：小型微利企业优惠
- 年应纳税所得额≤300万元部分，实际税率5%
- 通过合法业务分拆，使更多利润享受优惠税率
- 需注意：关联企业不得通过拆分利润套取优惠

### 方案3：研发费用加计扣除
- 2026年制造业研发费用加计扣除比例提高至120%
- 其他企业100%加计扣除
- 核算要点：研发费用需单独归集、建立辅助账

### 方案4：固定资产加速折旧
- 500万元以下设备器具可一次性税前扣除
- 500万元以上可加速折旧或缩短折旧年限
- 适用于设备投入大的制造类企业

### 方案5：业务分拆筹划
- 将不同业务板块分拆为独立小微企业
- 各自享受小微企业所得税优惠
- ⚠️ 需满足三性原则，不得被认定为套取优惠

### 方案6：税负洼地布局
- 西部大开发地区企业所得税15%
- 海南自贸港鼓励类产业15%
- 各地产业园区的税收返还政策

### 方案7：收入确认递延
- 合理推迟收入确认时间（分期收款、跨年安排）
- 等于获得一笔"无息贷款"
- 需符合会计准则和税法规定

### 方案8：费用扣除最大化
- 全额利用公益捐赠扣除（利润12%）
- 合理提高员工福利（补充医疗保险、企业年金）
- 业务招待费、广告费的报销限额管理

### 方案9：股东收益筹划
- 工资 vs 年终奖 vs 分红的税负平衡
- 股东借款需在年底前归还，避免视同分红
- 以公司名义购买资产（作为公司资产）

### 方案10：合同涉税条款优化
- 明确价格含税/不含税
- 正确选择发票类型（专票 vs 普票）
- 业务实质描述要准确（服务 vs 特许权）

### 方案11：关联交易合规定价
- 集团内定价需符合独立交易原则
- 准备同期资料文档备查
- 避免转让定价被税务机关调整

### 方案12：特殊行业优惠
- 高新技术企业（15%）
- 软件企业（两免三减半）
- 技术先进型服务企业（15%）
- 重点群体创业就业税收扣减

## 四、代账公司如何开展税务筹划服务

### 服务定位
代账公司可以从基础记账报税延伸到**税务筹划增值服务**：

| 服务层级 | 服务内容 | 客单价参考 |
|---------|---------|-----------|
| 基础层 | 记账报税、出具报表 | 200-800元/月 |
| 增值层 | 税务筹划、节税方案 | 500-2,000元/月 |
| 顾问层 | 常年财税顾问、投融资规划 | 3,000-10,000元/月 |
| 专项层 | 高新认定、重组筹划、IPO辅导 | 按项目10万+ |

### 实施四步法

1. **诊断阶段**：扫描客户纳税结构，识别高税负点
2. **建模阶段**：测算不同方案节税效益
3. **备案阶段**：向主管税务机关提交税收筹划备案
4. **监控阶段**：建立税务风险动态评估机制

### 风险防控要点

1. **证据链管理**：所有税收优惠申请备齐合同、流水、凭证
2. **时效把控**：注意各类优惠的申报截止日期
3. **规避雷区**：严禁虚构交易、体外循环、暴力避税
4. **定期健康检查**：每季度为客户进行税务健康检查
