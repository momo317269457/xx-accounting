# 代理记账公司管理制度大全

> 来源：七彩阳光企业商服网 (ingc.cn)

## 一、内部财务管理制度

### （一）基本原则

1. 公司会计应遵循权责发生制原则。

### （二）基本任务和方法

1. 筹集资金和有效使用资金，监督资金正常运行，维护资金安全
2. 做好财务管理基础工作，建立健全财务会计管理制度
3. 加强财务会计管理，提高会计信息的及时性和准确性
4. 监督公司财产的购买、建造、保管和使用
5. 按期编制各类会计报表和财务报表，做好分析评估工作

### （三）基本内容

1. **原始凭证管理**：实现制度化、规范化
2. **会计凭证管理**：内容必须包括日期、编号、业务汇总、会计科目、金额、所附原始凭证数量、制单人、审核人及会计主管签名或盖章
3. **会计核算**：按国家统一会计制度规定设置会计账簿，以实际经济业务为基础
4. **会计审计**：经办财务人员要认真检查各项业务的合法性、真实性、程序完整性和数据准确性
5. **账实核对**：定期与实物盘点、货币资金、往来账户核对
6. **会计档案**：会计凭证、会计账簿、会计报表等应建立档案妥善保管
7. **会计交接**：工作变动或辞职必须办理交接手续，有主管负责监交

## 二、业务标准体系

### 签署《代理记账委托协议书》

**客户义务：**
1. 对发生的经济业务事项填制或取得合法、真实、准确的原始凭证
2. 配备专业人员负责日常货币收支和保管
3. 及时向公司提供合法、真实、准确、完整的原始凭证及相关资料
4. 对退回的需要更正和补充的原始凭证及时更正补充
5. 承担委托协议约定的责任

**公司义务：**
1. 遵守会计法律法规和国家统一的会计制度
2. 对执行业务过程中知悉的商业秘密负有保密义务
3. 对不符合法律法规要求的应予以拒绝
4. 负责解释委托人提出的有关会计处理的原始问题
5. 承担委托协议约定的责任

## 三、代理记账公司规章制度要点

### 内部机构设置

代理记账公司应设置以下部门：
1. **业务部**：负责客户拓展、业务承接
2. **咨询部**：提供财税咨询服务
3. **会计部**：负责账务处理
4. **审核部**：负责账务审核

### 代理记账业务负责人岗位职责

1. 审核记账凭证，确保原始单据符合规定、记账科目符合会计规定
2. 最终审核财务报表，确保财务报表正确合理

## 四、代账公司选择标准

### 核查核心资质（一票否决项）

1. 必须持有《代理记账许可证》
2. 营业执照经营范围中必须包含"代理记账"字样

### 5步筛选法

1. **查资质**：财政局官网查询代理记账机构信息
2. **看实力**：优先选择成立5年以上、有固定办公场所、会计团队10人以上的公司
3. **问流程**：是否有严格账务审核流程、1对1专属会计服务模式
4. **明收费**：收费透明，警惕低于100元/月的低价陷阱
5. **查口碑**：查看法律诉讼和行政处罚记录，咨询身边创业者

### 常见7大坑

1. **低价陷阱**：99元/月吸引客户，后期各种隐形收费
2. **隐形消费**：账本费、报税服务费、资料打印费等
3. **无证经营**：没有代理记账许可证私自开展业务
4. **账务混乱**：招聘无证实习生做账
5. **报税逾期**：一个会计对接太多客户导致逾期
6. **不交接资料**：终止合作时拒绝交接账本凭证
7. **泄露商业机密**：不正规公司泄露财务信息
