# 工商注册/变更/注销全流程指南

> 综合来源：政府网站、知乎专栏、搜狐、一帆财税等
> 整理时间：2026年6月

---

## 第一部分：公司注册（设立登记）

### 一、注册前的准备工作

#### 1. 确定基本信息

| 项目 | 说明 |
|------|------|
| **公司名称** | 格式：城市+字号+行业+有限公司。准备3-5个备选名称 |
| **注册资本** | 认缴制（无需实缴），建议10万-100万 |
| **经营范围** | 按国民经济行业分类规范填写，注意前置许可项目 |
| **注册地址** | 需为商业/办公用途，住宅有限制 |
| **股东信息** | 股东身份证、出资比例、联系方式 |
| **法人/监事/财务** | 至少需3个不同的人担任（法人可兼执行董事） |

#### 2. 注册所需材料清单

**基础材料：**
- 法人、股东、监事身份证原件及复印件
- 注册地址证明（房产证复印件/租赁合同/场地使用证明）
- 公司名称预先核准通知书（线上申请）
- 公司章程（可在工商系统下载模板）
- 股东会决议/股东决定
- 企业设立登记申请书

**特殊行业附加材料：**
- 食品/医疗器械类：前置审批许可证
- 建筑工程类：资质证书或技术人员资格证明
- 教育培训类：办学许可证

---

### 二、注册全流程步骤

#### 第1步：线上核名（1个工作日）
- 登录当地政务服务网或市场监督管理局网站
- 提交3-5个备选名称
- 系统自动查重，通过后获得《企业名称预先核准通知书》

#### 第2步：提交设立申请（1-3个工作日）
- 线上提交所有材料扫描件
- 系统自动审核或人工审核
- 审核通过后领取营业执照（电子版+纸质版）

#### 第3步：刻章备案（1个工作日）
- 公章、财务章、法人私章、合同章、发票章
- 公安备案刻章点办理，费用300-500元

#### 第4步：银行开户（3-7个工作日）
- 法人携带执照、印章、身份证到银行面签
- 开设公司基本账户
- 可选：一般账户、专用账户

#### 第5步：税务登记（30日内完成）
- 登录电子税务局完成税种核定
- 小规模纳税人建议选季度申报
- 一般纳税人需确认资格认定

#### 第6步：社保/公积金开户
- 社保登记：电子税务局或社保局
- 公积金开户：公积金管理中心

---

### 三、注册费用参考

| 项目 | 费用范围 |
|------|---------|
| 工商注册（政府收费） | 0元（政府减免） |
| 刻章 | 300-500元 |
| 银行开户 | 0-500元（不同银行） |
| 代理注册服务 | 500-2,000元 |
| 注册地址（挂靠） | 3,000-8,000元/年 |
| 代理记账（小规模） | 2,400-3,600元/年 |
| 代理记账（一般纳税人） | 4,000-8,000元/年 |

## 第二部分：工商变更

### 一、常见变更类型

| 变更类型 | 适用场景 | 办理周期 |
|---------|---------|---------|
| 公司名称变更 | 公司品牌升级、重新定位 | 3-5个工作日 |
| 经营范围变更 | 新增/调整业务领域 | 3-5个工作日 |
| 注册资本变更 | 增资/减资 | 5-10个工作日 |
| 股权变更 | 股东退出/新股东加入 | 5-10个工作日 |
| 法人/董事变更 | 管理层调整 | 3-5个工作日 |
| 注册地址变更 | 搬迁办公室 | 5-10个工作日 |

### 二、变更通用流程

#### 线上变更（推荐）：
1. 登录当地政务服务网
2. 选择"企业变更登记"
3. 填写变更事项、上传材料
4. 电子签名（法人、股东使用个人U盾或数字证书）
5. 提交审核，等待领证

#### 线下变更：
1. 领取并填写《公司变更登记申请表》
2. 准备股东会决议、章程修正案等材料
3. 携带公章、营业执照原件到工商窗口办理
4. 领取换发的营业执照

### 三、各类变更所需材料

#### 名称变更
- 公司变更登记申请书
- 股东会决议/决定
- 公司章程修正案
- 营业执照正副本原件
- 新名称预先核准通知书

#### 经营范围变更
- 公司变更登记申请书
- 股东会决议/决定
- 公司章程修正案
- 营业执照正副本原件
- 新增经营范围涉及前置许可的，需提供许可证

#### 股权变更（重点）
- 股权转让协议（明确转让价格、比例）
- 原股东会决议（同意转让、放弃优先购买权）
- 新股东会决议（章程修正案等）
- 公司章程修正案
- 营业执照正副本、公章
- 新老股东身份证原件
- 个人所得税完税凭证（税务申报完成后）

**⚠️ 特别注意**：股权转让必须先到税务部门申报个人所得税，取得完税凭证后方可到工商办理变更登记。

#### 地址变更
- 公司变更登记申请书
- 股东会决议/决定
- 新地址使用证明（房产证/租赁合同）
- 营业执照正副本原件

#### 法人变更
- 公司变更登记申请书
- 股东会决议/决定
- 原法人免职证明、新法人任职证明
- 新法人身份证原件
- 营业执照正副本原件

## 第三部分：公司注销

### 一、判断注销类型

| 类型 | 适用条件 | 办理周期 | 特点 |
|------|---------|---------|------|
| **简易注销** | 无债权债务、未开业或无涉税事项 | 20-30天 | 流程简单、无需清算组 |
| **一般注销** | 有债权债务、税务异常的常规企业 | 2-6个月 | 需清算组、流程完整 |
| **强制注销** | 吊销执照/责令关闭满3年未注销 | 由登记机关执行 | 股东责任不受影响 |

### 二、简易注销流程

**适用条件：**
- 未开业或无债权债务
- 未办理过涉税事宜，或已办结清税
- 未被列入经营异常名录
- 无股权冻结、出质等情形

**流程：**
1. **公示**（20天）
   - 登录国家企业信用信息公示系统
   - 发布简易注销公告及全体投资人承诺书
   - 公示期20天

2. **申请注销登记**（公示期满后20-50天内）
   - 提交简易注销登记申请书
   - 全体投资人承诺书
   - 营业执照正副本

3. **领取注销通知书**
   - 审核通过后领取准予注销登记通知书

### 三、一般注销流程（完整版）

**第1步：成立清算组**
- 股东会决议成立清算组
- 清算组成员由股东或董事担任
- 明确清算组职责

**第2步：公示清算信息**
- 登录国家企业信用信息公示系统
- 发布清算组信息和债权人公告（45天）
- 债权人可在公告期内申报债权

**第3步：税务注销（关键环节）**
- 向主管税务机关申请清税
- 结清应纳税款、滞纳金、罚款
- 缴销发票和税控设备
- 取得清税证明（免办/即办/一般流程）

**第4步：清算报告**
- 清算组编制清算报告
- 股东会确认清算报告

**第5步：工商注销登记**
- 提交注销登记申请书
- 清算报告、股东会决议
- 营业执照正副本
- 清税证明

**第6步：其他注销**
- 银行账户注销
- 社保/公积金账户注销
- 公章缴销

### 四、税务注销三种情形

| 情形 | 说明 | 办理方式 |
|------|------|---------|
| **免办** | 未办理过涉税事宜，或已办税但未领发票、无欠税 | 直接向工商申请简易注销 |
| **即办** | 无欠税、已缴销发票、纳税信用A/B级 | 当场出具清税证明 |
| **一般流程** | 不符合免办/即办条件的 | 提交材料→审查→审批 |

### 五、注销常见问题

| 问题 | 解决方案 |
|------|---------|
| 营业执照丢失 | 先登报挂失，再凭遗失声明办理 |
| 公司有未结清税款 | 先补税缴滞纳金，再办理注销 |
| 股东失联/不配合 | 通过报纸公告，或向法院申请强制清算 |
| 账册凭证丢失 | 向税务局书面说明情况，接受处罚后办理 |
| 公司有诉讼未结 | 等待诉讼结束后再办理注销 |
