## 模块一：行业入门与全景

### 1.1 什么是代理记账

根据《中华人民共和国会计法》第三十六条，不具备设置会计机构条件的单位，应当委托经批准设立从事会计代理记账业务的中介机构代理记账。

### 1.2 代理记账 vs 兼职会计 vs 全职会计

| 对比维度 | 代理记账公司 | 兼职会计 | 全职会计 |
|---------|------------|---------|---------|
| 年度成本 | 小规模2,000-3,600元 | 12,000-24,000元 | 80,000-150,000元 |
| 专业能力 | 团队服务，多人审核 | 个人能力参差不齐 | 取决于个人薪资 |
| 稳定性 | 公司化运营，服务连续性强 | 随时可能离职 | 离职率高 |
| 风险承担 | 合同约定，机构承担 | 无赔偿能力 | 最多开除员工 |

**结论**：年营收低于1,000万、员工少于50人的中小企业，优先选择正规代理记账公司。

### 1.3 行业规模数据

- 全国取得行政许可的代理记账机构**超过10万家**
- 从业人员**超过30万人**
- 服务覆盖全国数千万家中小微企业

### 1.4 2026年行业新趋势

详见：📄 `doc/2026年代账行业新规与监管趋势.md`

| 趋势 | 影响 |
|------|------|
| 财政部/市场监管/税务联合监管 | 合规成本上升，不规范机构加速淘汰 |
| 实名备案制 | 从业人员需完成实名登记 |

### 2.3 绩效考核与提成

详见：📄 `doc/代账公司会计绩效考核与提成方案.md`

**核心薪资结构：**
```
总薪资 = 基本工资 + 岗位工资 + 绩效工资 + 提成 + 福利补贴
```

**5个核心岗位KPI指标：**
- 记账会计：客户数量、账务处理及时率、错误率
- 审核会计：审核覆盖率、差错发现率
- 税务专员：申报及时率、风险预警准确率
- 销售顾问：新签客户数、销售额
- 客服专员：续费率、客户满意度

**阶梯式提成计算法：**
- 基础客户数（如50家以内）：固定提成
- 目标客户数（如50-80家）：提成上浮20%
- 超额客户数（如80家以上）：提成上浮50%

**质量系数**：提成与服务质量挂钩（出错的会计扣减提成）。

### 2.4 财政部新规对人员的要求

- 必须有**3名以上专职从业人员**
- 主管必须具有**会计师以上专业技术职务资格**或从事会计工作**不少于三年**
- 从业人员每年需参加**继续教育**

## 模块三：工作流程与SOP

### 3.1 总流程视图

详见：📄 `doc/代账公司工作流程.md` | `doc/代账公司SOP标准化流程.md` | `doc/工作流程.md`

```
客户签约 → 资料交接 → 票据整理 → 凭证录入 
  → 账务审核 → 纳税申报 → 出具报表 → 档案归档
       ↓           ↓          ↓          ↓
   三级复核    申报前校验   客户确认   年度汇算清缴
```

### 3.2 接票环节标准化

详见：📄 `doc/代账公司工作流程.md` 第一章

**关键控制点：**
- 建立统一的客户资料清单模板
- 实行双人核对制度
- 使用电子化交接系统
- 每次交接填写《原始凭证交接表》（财政部推荐范例）

**交接时间节点：**
- 每月1-5日：客户递送上月票据
- 每月5-10日：票据整理、分类、扫描
- 每月10-15日：账务处理

### 3.3 做账环节

**"三审三查"机制：**

```
第一级：录入员 → 票据信息录入，系统自动价税分离
第二级：主办会计 → 账务逻辑审核（成本费用配比、往来款合理性）
第三级：主管会计 → 复核税金计算、利润结转等关键数据
```

### 3.4 报税环节

**申报前校验清单（12项）：**
1. 进项发票认证状态 ✓
2. 销项税额与开票系统一致性 ✓
3. 增值税申报表与账务数据一致 ✓
4. 所得税预缴数据准确性 ✓
5. 财务报表平衡性检查 ✓
6. 往来款项异常分析 ✓
7. 银行余额调节表核对 ✓
8. 工资薪金与个税申报一致性 ✓
9. 固定资产折旧计算准确性 ✓
10. 待摊/预提费用合理性 ✓
11. 关联交易定价公允性 ✓
12. 税收优惠适用资格确认 ✓

## 模块八：经营与财务

### 8.1 定价策略

详见：📄 `doc/代账公司收费标准与价格对比.md`

**2026年各城市收费标准：**

| 城市级别 | 小规模纳税人（月费） | 一般纳税人（月费） |
|---------|-------------------|------------------|
| 一线城市 | 300-500元 | 500-800元 |
| 新一线 | 200-300元 | 400-600元 |
| 二三线城市 | 150-250元 | 300-500元 |
| 零申报 | 50-150元 | 100-200元 |

**核心定价因素：**
- 纳税人类型（小规模 vs 一般纳税人，价差2-3倍）
- 开票量/营业额
- 行业复杂度（餐饮/建筑比科技公司贵30-50%）
- 地区（一线比三四线高40-60%）
- 服务深度（基础 vs 含筹划等增值服务）

**价格陷阱提醒：**
1. "99元/月"超低价 → 引流款，隐形收费
2. 隐形费用 → 工商变更、税务异常处理额外收费
3. 兼职会计 → 低于200元/月的多是无资质个人
4. 低价套餐缩水 → 不含汇算清缴、年报

### 8.2 财税软件选型

详见：📄 `doc/代账公司财税软件选型对比.md`

**代账公司专用软件对比：**

| 软件 | 适用规模 | 核心优势 | 参考价格 |
|------|---------|---------|---------|
| 畅捷通易代账 | 中小型 | 智能记账、一键申报 | 2,000-5,000元/年 |
| 慧算账 | 各类 | SaaS、OCR识别、风险预警 | 按账套收费 |
| 金蝶精斗云 | 中小型 | 云原生、AI智能 | 3,000-8,000元/年 |
| 大账房 | 中大型 | 全流程自动化 | 按需定制 |

**选型建议：**
- 小型代账公司（<50家客户）→ 畅捷通易代账或账信云
- 中型代账公司（50-200家客户）→ 慧算账或金蝶精斗云
- 大型代账公司（>200家客户）→ 大账房或定制化方案

**2026年技术趋势：**
- AI大模型深度应用（自然语言查账、财务分析）
- 全电发票全面普及
- 业财税一体化（业务发生即记账）
- 数据增信（会计数据→信用评估→银行贷款）

### 9.2 代账公司常见盈利模型

**收入结构：**

```
基础代账收入（60-70%）
  ├── 小规模纳税人（月200-400元/户）
  └── 一般纳税人（月400-800元/户）
  
增值服务收入（20-30%）
  ├── 税务筹划（月500-2,000元/户）
  ├── 工商代办（单次500-3,000元）
  ├── 出口退税（年3,000-10,000元/户）
  └── 财税顾问（月3,000-10,000元/户）

其他收入（5-10%）
  ├── 地址挂靠（年3,000-8,000元）
  ├── 培训服务
  └── 软件销售/代理
```

**成本结构：**

```
人力成本（60-65%）→ 会计/销售/行政人员工资
软件成本（5-8%）→ 财税软件/客户管理软件
办公成本（8-10%）→ 房租/水电/办公用品
营销成本（5-10%）→ SEM/信息流/活动
其他（10-15%）→ 税费/保险/培训/杂费
```

**盈亏平衡测算：**
- 人均管户50家，每户均价300元/月
- 人均月产出：50×300=15,000元
- 人均成本（含社保）：8,000-12,000元/月
- 人均毛利：3,000-7,000元/月
- **当客户达到150家以上（3人团队），月净利润可达1-2万元**
